
# coxof AI DIY V1.0

## 产品定位

coxof AI DIY 是一个以 POD 产品定制为核心的 AI 设计平台。

系统不是通用 AI 创作工具，也不是电商运营后台。

## 核心用户流程

1. 用户选择 POD 产品
2. 用户输入文字提示词或上传参考图片
3. AI 生成设计图
4. 用户在画布中调整设计
5. 用户查看产品 Mockup
6. 用户保存项目
7. 用户提交定制订单

## 产品设计原则

- 产品优先，而不是模型优先
- 用户先选择产品，再进入 AI 设计
- 默认界面简单，高级参数折叠
- 每一个页面都服务于 POD 定制流程
- 不增加与 V1.0 无关的功能
